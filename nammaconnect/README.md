# 🗣️ NammaConnect — Your Everyday Kannada Companion

**Breaking language barriers. Making Karnataka feel like home.**

NammaConnect is a beginner-friendly Kannada communication companion designed for people visiting Karnataka from other states. It helps users communicate with local Kannada speakers in everyday situations using useful phrases, English meanings, transliterations, and audio playback.

## 🌟 The Problem

People visiting Karnataka may struggle to communicate when they don't understand Kannada. Everyday situations—such as finding a bus stop, ordering food, asking for directions, or seeking help—can become stressful when there is a language barrier.

## 💡 Our Solution

NammaConnect makes everyday communication easier by helping users find the right Kannada phrase for their situation and play its audio.

Its standout feature, **Mission Mode**, guides users through a real-life scenario and prepares a relevant Kannada message they can play or show to another person.

## ✨ Key Features

- 🎯 **Mission Mode:** Select a real-life situation and get a relevant Kannada message.
- 🔊 **Kannada Audio:** Play supported Kannada phrases aloud.
- 🔄 **Smart Retry:** Get an alternative phrase if the first message isn't understood.
- 📚 **Everyday Phrases:** Explore useful phrases for travel, food, college, and health-related situations.
- 🔎 **Phrase Search:** Find phrases using the available search feature.
- ❤️ **Saved Phrases:** Keep useful phrases handy.
- 🗣️ **Practice Mode:** Practise Kannada phrases at your own pace.

## 🎯 Who Is It For?

- Students moving to Karnataka for college.
- Visitors and tourists exploring Karnataka.
- People from other states living or working in Karnataka.
- Beginners who want to learn useful Kannada expressions.

## 🚀 Run the Project Locally

### Prerequisites

Install [Node.js](https://nodejs.org/) and Git.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Abhijnashetty07/nammaconnect.git
   ```

2. Open the project directory:

   ```bash
   cd nammaconnect
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
